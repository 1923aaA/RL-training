# 删除"当前位置"和"速度"字段修改说明

## 修改时间
2026-04-03

## 修改原因
- "当前位置"字段已不再用于节点布局(已改用自动计算布局)
- "速度"字段在当前系统中未被实际使用
- 简化数据结构,减少数据冗余

## 影响范围

### ✅ 不受影响的功能
1. 节点布局 - 已改用自动计算布局,不依赖"当前位置"
2. 节点渲染 - 颜色、大小、标签等显示正常
3. 图例显示 - 组网分类和退网节点图例正常
4. 连接线显示 - 组网内和组网间连接正常

### ✅ 更新的功能
1. **鼠标悬停提示 (Tooltip)**
   - 不再显示"当前位置"和"速度"
   - 仅显示: 节点标识符、角色、状态、组网信息

### ❌ 移除的功能
1. 无法查看节点的原始坐标位置
2. 无法查看节点速度信息

## 迁移建议

### 如果需要恢复"速度"信息
可以在后端系统中单独维护速度数据,通过其他接口提供:
```json
// 单独的速度数据文件 (可选)
{
  "node_speeds": {
    "1": "1.5m/s",
    "2": "0.8m/s",
    ...
  }
}
```

### 如果需要保留"当前位置"作为参考
可以添加注释字段,但不用于渲染:
```json
{
  "节点标识符": 1,
  "角色": "中心节点",
  "组网信息": "组网 1",
  "状态": "在网",
  "_comment_position": "原始位置: [19.2, 16.5] (仅供参考)"
}
```

# 节点布局算法更新说明

## 修改时间
2026-04-03

## 修改内容
将网络拓扑图的节点布局从**基于"当前位置"的固定坐标**改为**基于组网的自动均匀分布**。

---

## 旧逻辑 (已废弃)

### 位置计算方式
```javascript
x: node['当前位置'] ? node['当前位置'][0] * 20 : null
y: node['当前位置'] ? node['当前位置'][1] * 20 : null
```

### 问题
- 依赖 JSON 数据中的 `"当前位置"` 字段
- 位置固定,不会根据组网数量和节点数量自动调整
- 需要手动维护每个节点的坐标

---

## 新逻辑 (已实施)

### 布局算法

#### 第一步: 数据分组
- 按 `"组网信息"` 将节点分组
- 将 `"状态": "退网"` 的节点单独分组

#### 第二步: 画布区域划分
- **画布尺寸**: 1200 x 800 (可调整)
- **边缘留白**: 50px
- **网格布局规则**:
  - 组网数 ≤ 2: 横向排列 (1行)
  - 组网数 ≤ 4: 2x2 网格
  - 组网数 > 4: 自动计算 N x M 网格

#### 第三步: 组网内节点分布
对每个组网的节点采用**圆形布局**:

1. **中心节点**:
   - 角色为 `"中心节点"` 的节点放在区域中心
   
2. **其他节点**:
   - 围绕中心节点均匀分布在圆周上
   - 圆的半径 = `min(区域宽度, 区域高度) * 0.35`
   - 节点间角度间隔 = `360° / (节点总数 - 1)`

3. **特殊情况**:
   - 如果组网只有1个节点,直接放在区域中心

#### 第四步: 退网节点处理
- 放置在画布底部一排
- 横向均匀分布
- 节点间距不超过 100px

## 代码示例

### 网格布局计算
```javascript
const totalClusters = 4; // 假设有4个组网
const gridCols = 2;      // 2列
const gridRows = 2;      // 2行
const cellWidth = (1200 - 100) / 2 = 550;
const cellHeight = (800 - 100) / 2 = 350;
```

### 组网区域分配
```
┌─────────────────────────────────┐
│  组网 1  │  组网 2  │
│          │          │
├──────────┼──────────┤
│  组网 3  │  组网 4  │
│          │          │
└─────────────────────────────────┘
```

### 圆形布局示例 (组网 1 有 8 个节点)
```
        节点3
    节点2   节点4
节点1          节点5
   【中心节点】
节点8          节点6
    节点7
```

## 优点

1. **自动适应**: 无需手动配置节点坐标
2. **视觉清晰**: 组网分区明确,易于识别
3. **动态调整**: 节点数量变化时自动重新分布
4. **美观整齐**: 圆形布局对称美观

---

## 参数调整

如需调整布局效果,可修改以下参数 (位于 `js/index.js` 的 `renderNetworkTopologyChart` 函数):

```javascript
const canvasWidth = 1200;   // 画布总宽度
const canvasHeight = 800;   // 画布总高度
const padding = 50;         // 边缘留白
const radius = Math.min(cellWidth, cellHeight) * 0.35; // 圆形半径系数 (0.35)
```

## 数据字段变化

### 不再使用的字段
- `"当前位置"` - 保留在数据中用于其他用途(如提示信息),但**不再用于画图**

### 依赖的字段
- `"组网信息"` - 用于节点分组和区域分配
- `"角色"` - 用于判断中心节点和节点大小
- `"状态"` - 用于识别退网节点

# 跨组网节点支持功能说明

## 功能概述
支持同一个节点同时属于多个组网,并在拓扑图上将跨组网节点显示在多个组网区域的交界处。

---

## 数据格式

### 支持的数据结构
允许同一个节点标识符在 `data` 数组中出现多次,每次关联不同的组网:

```json
{
  "data": [
    { "节点标识符": 10, "角色": "成员节点", "组网信息": "组网1-STDMA", "状态": "在网" },
    { "节点标识符": 10, "角色": "成员节点", "组网信息": "组网2-TDMA", "状态": "在网" }
  ]
}
```

**说明**: 节点10同时属于组网1和组网2

---

## 前端处理逻辑

### 第一步: 节点分类

#### 1.1 构建节点-组网映射
```javascript
const nodeClusterMap = {}; // 节点ID -> 所属组网列表
```

遍历所有数据记录,将每个节点的组网关系记录下来。

#### 1.2 识别跨组网节点
- **跨组网节点**: 出现在2个或更多组网中的节点
- **单组网节点**: 只出现在1个组网中的节点

```javascript
if (clusters.length > 1) {
    // 跨组网节点
    crossClusterNodes.push(...);
} else {
    // 单组网节点
    singleClusterNodes[clusterName].push(...);
}
```

---

### 第二步: 位置计算

#### 2.1 单组网节点
- 在各自组网的区域内,使用圆形布局均匀分布
- 逻辑与之前相同

#### 2.2 跨组网节点

##### 两个组网的情况
```javascript
// 计算两个组网中心的中点
x = (center1.centerX + center2.centerX) / 2;
y = (center1.centerY + center2.centerY) / 2;
```

**效果**: 节点位于两个组网区域的交界线中央

##### 多个组网的情况
```javascript
// 计算所有组网中心的平均值
x = sumX / count;
y = sumY / count;
```

**效果**: 节点位于所有相关组网区域的几何中心

---

### 第三步: 视觉样式

#### 跨组网节点的特殊样式

1. **颜色混合**
   ```javascript
   // 混合所有所属组网的颜色
   const colors = ['#FF4949', '#FFA74D']; // 组网1红色 + 组网2橙色
   const mixedColor = mixColors(colors);  // 结果: #FF784B (橙红色)
   ```

2. **符号形状**
   - 单组网节点: 圆形 `circle`
   - 跨组网节点: 菱形 `diamond` ◆

3. **边框标识**
   ```javascript
   borderColor: '#fff',
   borderWidth: 2  // 白色边框
   ```

4. **大小调整**
   - 跨组网节点稍大于单组网节点 (+2px)
   - 突出显示其特殊身份

5. **标签样式**
   ```javascript
   fontWeight: 'bold'  // 加粗字体
   ```

## 扩展性

### 支持3个或更多组网的节点
代码已自动支持!

**示例**: 节点X同时属于组网1、组网2、组网3
```javascript
// 位置: 3个组网中心的平均值
x = (center1.x + center2.x + center3.x) / 3;
y = (center1.y + center2.y + center3.y) / 3;

// 颜色: 混合3个颜色
mixedColor = mixColors(['#FF4949', '#FFA74D', '#77CD63']);
// 结果: #BA7F53 (棕橙色)
```

## 使用指南

### 添加跨组网节点
只需在 JSON 数据中为同一节点ID添加多条记录:

```json
{
  "data": [
    { "节点标识符": 15, "角色": "成员节点", "组网信息": "组网2-TDMA", "状态": "在网" },
    { "节点标识符": 15, "角色": "成员节点", "组网信息": "组网3-CSMA", "状态": "在网" }
  ]
}
```

前端会自动:
- 识别节点15为跨组网节点
- 计算组网2和组网3的交界位置
- 使用混合颜色和菱形显示

**无需修改前端代码!**

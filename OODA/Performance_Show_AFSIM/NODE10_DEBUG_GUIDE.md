## 排查步骤

### 步骤1: 检查数据是否正确加载
在控制台查看是否有以下输出:
```
跨组网节点: [10]
```

**如果没有**:
- 检查 `Cluster_info.json` 是否包含两条节点10的记录
- 检查浏览器是否缓存了旧的JSON文件
- 尝试硬刷新: `Ctrl + F5`

### 步骤2: 检查节点是否添加到nodes数组
查看控制台:
```
跨组网节点 10 已添加到nodes数组, 总节点数: 24
```

**如果总节点数不是24**:
- 说明某些节点未被处理
- 检查是否有JavaScript错误

### 步骤3: 检查图例是否包含跨组网类别
查看控制台:
```
categories 内容: ["组网1-STDMA", "组网2-TDMA", "组网1-STDMA & 组网2-TDMA"]
```

**如果缺少跨组网类别**:
- 图例项未正确添加
- ECharts可能不显示没有图例的节点

### 步骤4: 检查坐标是否合理
查看控制台:
```
节点10位置: (600, 400), 颜色: #ff784b
```

**如果坐标异常**:
- (600, 400) 应该在画布中央
- 如果坐标是 (NaN, NaN) 说明计算有误

## 可能的问题及解决方案

### 问题1: ECharts过滤了没有图例的节点
**现象**: nodes数组包含节点10,但图上不显示

**原因**: 节点的 `category` 字段值在 `categories` 数组中找不到匹配

**解决方案**: ✅ 已实现
- 在生成图例时,自动为跨组网节点添加图例项

### 问题2: 坐标计算依赖未定义的变量
**现象**: 控制台显示 `centerX is not defined` 等错误

**原因**: `clusterCenters` 对象未正确构建

**检查**: 
```javascript
console.log('组网中心坐标:', clusterCenters);
```

### 问题3: 节点被图例过滤隐藏
**现象**: 初次加载时节点不显示

**原因**: 用户可能点击了图例,隐藏了某个类别

**解决**: 点击图例中的 `"组网1-STDMA & 组网2-TDMA"` 项,切换显示状态

### 问题4: symbol类型不支持
**现象**: 节点10的位置正确但不显示

**原因**: ECharts版本可能不支持 'diamond' 符号

**解决**: 改为其他符号
```javascript
symbol: 'rect'  // 使用矩形
symbol: 'triangle'  // 使用三角形
```

# 时序杀伤网分层分布式强化学习系统

## 项目简介

本项目实现了基于时序网络和分层强化学习的杀伤网优化系统，包含：

1. **多层网络建模**：物理层、功能层、任务层三层网络
2. **时序杀伤链生成**：基于时间序列的动态杀伤链构建
3. **分层决策架构**：战略层（任务参与）、战术层（链路选择）、操作层（模式选择）
4. **内生智能节点**：节点具备自主感知、决策和能力演化能力
5. **分布式强化学习**：基于PPO算法的多智能体协同学习

1. 神经网络的“乐高积木” (algorithms/utils/)
当代码运行到 r_actor_critic.py 想要创建一个智能体大脑时，它会像搭积木一样调用这些文件：
感知阶段 (Input)
	如果输入是图片 (Obs is Image) -> 调用 cnn.py (卷积层)。
	如果输入是向量 (Obs is Vector) -> 调用 mlp.py (全连接层)。
记忆阶段 (Memory)
	如果开启了 RNN (use_recurrent_policy) -> 调用 rnn.py。它让智能体能记住几秒前发生的事（比如“刚才谁撞了我？”）。
决策阶段 (Output)
	数据流向 act.py。它负责根据网络提取的特征，计算出动作的概率分布。
	它底层依赖 distributions.py。比如对于离散动作（上下左右），它会创建一个 FixedCategorical 分布，然后从中采样（Sample）一个动作。
价值评估阶段 (Critic)
	Critic 网络需要预测一个具体的分数（Value）。
	popart.py 在这里起大作用。它可以动态调整 Value 的均值和方差，防止奖励忽大忽小导致网络不收敛。这是一个比较高级的 Trick。

2. 整个系统如何“活”起来？
让我们跟踪一次完整的 Decision Making 过程：
眼 (Env): 看到画面 obs。
脑 (Policy):
	mpe_runner 把 obs 扔给 rMAPPOPolicy。
	rMAPPOPolicy 让 r_actor_critic 开始计算。
	mlp.py 提取特征 -> rnn.py 结合记忆 -> act.py 计算概率 -> distributions.py 采样。
	输出：动作 (Action)。
手 (Env): 执行动作，获得反馈。
胃 (Buffer): 把刚才看的东西、做的动作、吃到的奖励（Reward）全都存进 separated_buffer。
梦 (Train):
	r_mappo.py 从 Buffer 里回放记忆。计算 Loss，告诉 mlp.py, rnn.py 里的参数该怎么调整（Backprop）。
